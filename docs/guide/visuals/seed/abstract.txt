Node upgrades should be routine, yet many clusters still drop requests every time a node drains. PodDisruptionBudgets look simple, but readiness gaps, slow endpoint updates, and budgets that block eviction forever turn each maintenance window into an incident. This session walks through a drain from the first cordon to the last eviction and shows where traffic gets lost. Attendees learn how to size budgets for real replica counts, how to pair them with preStop hooks and readiness probes, and how to test a drain before the next upgrade.
